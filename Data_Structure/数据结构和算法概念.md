# 1. 数据结构的基本概率

- **数据：**
	- **对客观事物的符号表示**，是所有能输入到计算机中并被程序处理的符号总称。101，“张三”，95，“男”。
- **数据元素：**
	- 是**数据的基本单位**，计算机中通常作为一个整体进行考虑和处理。如：学号：101，姓名：“张三”，成绩：95，性别：“男”。其中：【学号：101】为数据项。
- **数据对象：**
	- 具有**相同性质的数据元素的集合**，是数据的子集。如：全班的花名册就是一个数据对象。它包含了”学生A数据元素“，”学生B数据元素“，”学生C数据元素“。
# 2. 数据结构三要素
- **什么是数据结构：**
	- 数据元素之间不是孤立存在的，它们之间存在某种关系，数据元素互相之间的关系称为结构，或者说数据结构是带结构的数据元素的集合。
- **数据结构包含三个方面的内容(三要素)：**
	- 逻辑结构、物理结构(存储结构)、数据运算和实现。
- **逻辑结构：**
	- 描述数据元素之间的逻辑关系。逻辑结构可以分为：线性结构、树形结构、图形结构(网状结构)、集合；也可以直接分为线性结构和非线性结构(树形、图形、集合)。
	- 线性结构中的数据元素之间存在一对一的关系，除了第一个元素，所有元素都有唯一前驱，除了最后一个元素，所有元素都有唯一后继。非线性结构可能有多个直接前驱和直接后继。
- **物理结构（存储结构）：** 比如：数组
	- 链式存储结构：数据元素之间的逻辑关系用指针来表达。
	- 散列结构（也叫哈希）：值后存储另外一个地址。

# 4. 算法的基本概率
- 算法(Algorithm)是**解决特定问题的求解步骤的一种描述**，是一系列解决问题指令的有限序列。它描述了如何通过一系列操作将输入转换为期望的输出。算法代表着用系统的方法描述解决问题的策略机制，精心设计的算法可以带来**更高的运行效率**。
- 算法 + 数据结构 = 程序
- 数据结构和算法的是紧密耦合、相辅相成的。
# 5. 算法的特性
- **有穷性**：算法必须在有限步骤内结束，不能无限循环或永远不终止。
- **确定性**：算法的每一步骤必须有确切、无歧义无二义性的定义。对于相同的输入必须得到相同的输出。
- **可行性**：算法是可执行的，算法中描述的操作都是通过已经实现的基本运算执行有限次来实现。
- **输入**：算法有零个或多个输入，这些输入取自特定的对象集合。
- **输出**：算法有一个或多个输出。输出是算法处理输入后得到的结果，与输入有特定关系。
# 6. 算法设计的要求
- **正确性**：算法能正确的解决求解的问题。
- **可读性**：算法的思路是便于理解的，可读性强的。
- **健壮性**：当输入数据非法时，算法也能适当的做出进行处理，而不会产生莫名其妙的结果。
- **高效率与低存储要求**：高效率就是执行之间尽可能低，低存储就是执行过程中使用更少的存储空间。
# 7. 算法的关注
- 我们一般不关注算法的最好，只是关注算法的最差。
